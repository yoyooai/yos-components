# Feature: 飞书上游 0.3.5 同步

## 背景

YOS 飞书渠道此前锁定 `zylos-ai/zylos-feishu 0.3.4`。上游 `0.3.5`
新增互动卡片、音视频、贴纸、引用富消息和合并转发内容读取。本轮只吸收
这批消息解析能力，不改 OS，不改微信渠道，也不改变 YOS 的主人绑定、
群权限、C4 幂等交付和本地数据目录。

## 关键决策

- 来源固定为上游提交 `a683464aee51d0318a98cb28581fc911b37c66ee`，
  归档 SHA-256 记录在 `provenance/upstream.json`。
- 两个纯解析模块按上游实现导入；入口只做选择性接线，保留 YOS 本地适配。
- 合并转发的 `im.message.get` 必须在私聊或群聊权限检查通过后执行。
- 嵌套转发限制为 3 层、最多 12 次额外读取，失败显式降级，不伪装为空消息。
- 上游未知卡片诊断会记录原始内容，YOS 改为固定诊断，避免扩大私聊内容暴露。

## 未采用方案

- 未整体覆盖 `src/index.js`：这会覆盖 YOS 的主人绑定、姓名解析、C4 与日志适配。
- 未同步 OS 或微信：两者当前没有需要本轮吸收的已合并上游能力。
- 未增加依赖：新模块全部使用 Node 标准能力和现有飞书 SDK。

## 测试结果

- 测试先行红灯：新测试在旧代码上因两个解析模块不存在而失败。
- 解析与接线专项：29/29 通过。
- 飞书完整套件：待版本门禁数字更新后记录最终结果。
- 整仓门禁、依赖审计、包清单与双构建：待最终验证。

## 交付边界

`0.1.4` 当前是候选版本。独立验收、标签、Registry 更新和对客发布均不在
本开发提交内；这些动作必须在锁定提交通过验收后另行执行。
