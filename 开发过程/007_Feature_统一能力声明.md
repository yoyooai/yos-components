# 飞书与微信统一能力声明

## 背景

YOS Components 已有安装合同，但无法按“消息能力”反向找到飞书和微信提供者。

## 实现

- 飞书和微信的 `SKILL.md` 声明同一个 `communication.message` 能力。
- 两者都声明 `send`、`receive` 操作；飞书为 `stable`，微信为 `beta`。
- 组件 ID、版本、YOS Core 兼容范围与 Node 范围继续以 `package.json` 为准。
- 仓库合同测试固定声明，未修改任何渠道运行代码、凭据处理或主人绑定逻辑。

未新建 `component.json`，也未在组件仓复制货架 URL、字节数或 SHA-256。
